Chrome Manifest V3 확장 프로그램입니다. **YouTube, Bilibili(빌리빌리), Dailymotion, Vimeo, Instagram, Facebook, TikTok** 등 지원 사이트의 동영상 페이지에서 **직접 클릭**하여 녹화를 시작하면, 탭 전체 화면과 페이지 오디오를 캡처하고 브라우저 내부에서 Canvas로 프레임 단위로 **플레이어의 실제 영상 영역(또는 직접 드래그해서 선택한 영역)**을 잘라낸 뒤, 최종적으로 **오디오가 포함된 동영상 파일**을 로컬에 다운로드합니다. 기본적으로 **MP4(H.264/AAC)**를 네이티브로 우선하며, 브라우저나 OS가 지원하지 않으면 자동으로 **WebM**으로 대체합니다.

녹화 대상 사이트는 자동으로 인식됩니다. 확장 프로그램이 현재 페이지의 도메인으로 사이트를 판별해 출력 파일명 접두사와 팝업 / 알림 속 사이트 문구를 자동으로 전환합니다(아래「지원 사이트」참고).

## 주요 기능

- **7대 동영상 사이트를 하나로 녹화**: YouTube / Bilibili(빌리빌리) / Dailymotion / Vimeo / Instagram / Facebook / TikTok의 공식 네이티브 동영상 페이지를 모두 동일한 파이프라인(tabCapture → 플레이어 찾기 → Canvas 크롭 → MediaRecorder)으로 녹화할 수 있습니다. 현재 사이트를 자동 인식해 파일명 접두사와 사이트 문구를 전환하며, 각 사이트의 신형·구형 플레이어 레이아웃 차이는 `src/shared/sites.js`에 통합해 한곳에서 관리합니다(아래「지원 사이트」참고).
- **서드파티 의존성 Zero**: npm 없음, 빌드 단계 없음, ffmpeg 없음, 재인코딩 전혀 없음(MP4는 `MediaRecorder`가 네이티브로 녹화하며, 녹화 후 변환하지 않습니다).
- **두 가지 녹화 모드**
  - **플레이어 전체**: `object-fit` / `object-position`을 계산해 플레이어의 *실제로 그려지는* 사각형을 자동으로 찾아 레터박스, 극장 모드 여백, 플레이어 외곽을 제외합니다.
  - **영역 선택**: 페이지에서 원하는 사각형을 드래그하여 그 영역만 녹화합니다.
- **항상 깨끗한 화면**: 모든 컨트롤은 확장 프로그램 아이콘 팝업(캡처 대상 탭의 렌더링에 포함되지 않는 독립된 확장 페이지)에 있으므로 확장 UI가 영상에 절대 등장하지 않습니다.
- **페이지 단축키**: 기본 단일 키 `R`은 대기 중일 때 녹화를 시작하고, 녹화 중에는 정지 후 저장합니다. 팝업 → **설정**에서 `Ctrl` / `Alt` / `Shift` / `Command` 조합으로 자유롭게 변경할 수 있습니다. 지원 사이트의 동영상 페이지에서만 동작하며 다른 탭의 키를 가로채거나 브라우저 전역 단축키와 충돌하지 않습니다.
- **녹화 중 페이지 잠금**: 반투명 마스크가 이미지 *바깥* 전체를 덮고(이미지 부분만 "구멍"을 냄) 스크롤, 클릭, 파괴적인 단축키를 차단합니다. 반면 **재생/일시정지, 탐색, 볼륨, 자막, 재생 속도는 그대로 사용할 수 있습니다**.
- **안정적인 크롭**: 30fps 고정 출력, 캔버스 크기는 첫 프레임에서 고정, 크롭 사각형이 3프레임 연속 안정된 뒤에야 녹화를 시작하므로 광고나 극장 모드 전환 시의 일시적으로 커진 사각형이 영상에 남지 않습니다.
- **오디오 손실 없음**: 캡처한 오디오 트랙을 `AudioContext`로 재생하여 탭이 음소거되어 무음 영상이 되는 것을 방지합니다.
- **전체 화면에서도 "녹화 중"이 보임**: 전체 화면으로 재생하면 화면이 가득 차서 마스크 안내를 둘 곳이 없습니다. 이때는 상주 시스템 알림과 항상 위에 표시되는 Document PiP 상태창(REC + 타이머 + 정지 버튼)으로 상태를 보여주며, 영상에 검은 레터박스가 있으면 그 안에 가는 빨간 테두리도 그립니다. 모든 인디케이터는 캡처 대상 영상의 바깥에 있어서 **영상에 절대 들어가지 않습니다**. 각 항목은 팝업의 **설정 → 전체 화면 녹화 상태 표시**에서 개별로 켜고 끌 수 있습니다.
- **충실한 예외 처리**: DRM 블랙 프레임 감지, 탭 전환/페이지 이동 시 자동 정지 후 내보내기, 사각형 하트비트 중단 시 자가 복구, 다운로드 실패 자동 재시도, 잔여 세션을 위한 "강제 초기화 후 다시 시작" 탈출구.
- **녹화는 오직 사용자 클릭으로만 시작**되며, 백그라운드 몰래 캡처는 절대 없습니다.

## 지원 사이트

녹화 파이프라인(tabCapture → 플레이어 찾기 → Canvas 크롭 → MediaRecorder)은 모든 사이트에서 완전히 동일하며, 다른 점은 세 가지뿐입니다: **주입 도메인**(`manifest.json`의 `content_scripts.matches`), **플레이어를 찾는 데 쓰는 DOM 선택자**, 그리고 **파일명 접두사 / 문구에 쓰는 사이트 이름**입니다. 아래 표가 현재 지원하는 사이트와 적용 가능한 페이지입니다:

| 사이트 | 녹화 가능한 페이지 형태 | 설명 및 제한 |
| --- | --- | --- |
| YouTube | 동영상 재생 페이지(`youtube.com/watch…`, Shorts 등) | 멤버십 / 유료 / DRM 영상은 검게 나옵니다(브라우저 보호, 아래 공통 제한 참고) |
| Bilibili(빌리빌리) | 동영상 재생 페이지(`bilibili.com/video/BV…`) | 신형 bpx와 구형 bilibili 플레이어를 모두 커버. 대형 회원 / DRM 제한 콘텐츠는 검게 나올 수 있음. **라이브 방송은 지원 범위 밖** |
| Dailymotion | 동영상 재생 페이지(`dailymotion.com/video/…`) | 플레이어 `<video>`가 크로스오리진 iframe / shadow DOM으로 감싸여 있을 때(메인 문서에서 읽을 수 없음) 플레이어 외부 컨테이너 사각형 탐지로 자동 대체 |
| Vimeo | 동영상 재생 페이지(`vimeo.com/…`) | 비공개 동영상은 로그인 및 조회 권한 필요 |
| Instagram | 게시물 / Reel / 스토리(열린 모달 보기), 홈 피드의 단일 동영상 | 일부 콘텐츠는 로그인해야 재생 가능한 동영상이 있음 |
| Facebook | Watch / Reel / 단일 동영상 오버레이 / 타임라인의 동영상 | 일부 콘텐츠는 로그인 필요. 타임라인에 여러 동영상이 있으면 "현재 보이는 메인 동영상"을 자동으로 선택 |
| TikTok | 동영상 상세 페이지(`tiktok.com/@…/video/…`), 열린 동영상 오버레이, For You 피드의 단일 항목 | 피드에 여러 프리뷰가 있으면 "재생 중 / 보이는 면적이 가장 큰" 항목을 자동으로 선택 |

> **탐지 메커니즘**: content 스크립트는 페이지에서 "실제로 보이는 `<video>`"를 기준으로 녹화 영역을 찾습니다. `src/shared/sites.js`가 각 사이트의 신형·구형 레이아웃의 플레이어 컨테이너 / video 후보 선택자를 일괄 관리하며, 컨테이너를 찾으면 내부 `<video>`를 가져와 `object-fit` / `object-position`으로 실제 그려지는 영상 사각형을 환산합니다(레터박스, 외곽, 여백 제외). 모든 후보가 빗나가면 "보이는 면적이 가장 큰 디코딩된 `<video>`"를 범용 폴백으로 사용합니다(열린 shadow DOM을 재귀적으로 커버). 따라서 메인 플레이어는 실제 `<video>`를 페이지 메인 문서(또는 읽을 수 있는 open shadow root)에 렌더링해야 합니다. **다른 웹페이지에서 크로스오리진 iframe으로 임베드된 플레이어는 지원 범위 밖**이며, 순수 canvas / WebGL처럼 `<video>`가 아닌 자체 그림 화면은 자동 탐지할 수 없으니 **영역 선택**을 사용하세요.

> **공통 제한**:
> - DRM / 유료 멤버십으로 보호된 동영상(각 플랫폼의 유료 영화, 구독 전용, 독점 라이선스 콘텐츠 등)은 캡처 화면에서 검게 나옵니다. 이는 브라우저의 "보호된 콘텐츠" 제한이지 확장 프로그램 결함이 아닙니다.
> - 로그인이 필요한 콘텐츠(Instagram / Facebook / TikTok의 대부분 동영상, Bilibili의 일부 애니 등)는 먼저 브라우저에서 해당 사이트에 로그인해 주세요.
> - 사이트 개편으로 선택자가 어긋나 페이지에 여러 개의 보이는 `<video>`가 있다면, 녹화 영역은 기본적으로 "보이는 면적이 가장 크고 디코딩 중인 것"을 선택합니다. 대상 동영상을 뷰포트 안에서 재생 상태로 유지하세요.

## 아키텍처(왜 offscreen document가 필요한가)

`chrome.tabCapture`는 content script에서 호출할 수 없습니다. 반면 크롭에 필요한 `video` / `canvas` / `MediaRecorder`는 DOM이 있는 창 컨텍스트에서 실행해야 합니다. 팝업은 포커스를 잃으면 닫히고 Service Worker에는 DOM이 없습니다. 그래서 녹화의 핵심은 **offscreen document**에 둡니다:

1. **content script**(자체 UI는 주입하지 않고 데이터만 보고)가 지원 페이지에서 플레이어를 찾아(`shared/sites.js`로 인식) 약 120ms마다 "실제 영상 사각형"과 뷰포트 기준(CSS 크기 / `devicePixelRatio` / visualViewport 오프셋)을 보고합니다.
2. **background**가 필요할 때 오프스크린 문서를 만들고, 사용자 제스처 체인 안에서 `chrome.tabCapture.getMediaStreamId()`를 호출해 `streamId`를 얻습니다.
3. **오프스크린**이 `getUserMedia({ chromeMediaSourceId: streamId })`로 탭 전체 스트림(영상 + 페이지 오디오)을 소비합니다.
4. **오프스크린** 내부 처리: 숨김 `video`가 탭 스트림 재생 → 숨김 `canvas`가 `drawImage`로 프레임 단위 크롭 → `canvas.captureStream(30)` 영상 트랙과 원본 `audioTrack` 합성 → `MediaRecorder`가 녹화(`video/mp4` 우선, 단계적으로 `video/webm`으로 폴백) → Blob 조립.
   - 좌표 변환은 `rect × devicePixelRatio` 같은 단순 계산이 아니라 **실측 비율**("캡처 프레임 크기 ÷ 뷰포트 CSS 크기", contain 모델과 중앙 패딩으로 보정)을 사용하므로 고해상도 화면 / 확대 환경에서도 어긋나지 않습니다.
5. 오프스크린은 `chrome.downloads`를 직접 호출할 수 없으므로 `DOWNLOAD_FILE` 메시지로 **background**에 대행시키고, `downloads.onChanged`로 결과를 받습니다.

자세한 내용은 `DESIGN.md`를 참고하세요.

## 확장 프로그램 로드(개발·디버그)

1. Chrome을 열고 `chrome://extensions`로 이동합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축 해제된 확장 프로그램을 로드합니다**를 클릭하고 이 저장소의 `src/` 디렉터리를 선택합니다(빌드 불필요, 컴파일 불필요).

> 요구 사항: Chrome 116 이상(`minimum_chrome_version`, `chrome.offscreen`에 필요). 네이티브 MP4 출력에는 Chrome 126 이상이 필요합니다. 최신 안정 버전을 권장합니다.

## 사용법

1. 지원 사이트의 동영상 페이지를 엽니다(위「지원 사이트」참고. 예: YouTube 재생 페이지, 빌리빌리 `video/BV…` 페이지, TikTok 동영상 상세 페이지 등. 최초 방문 시 스크립트 주입을 위해 한 번 새로고침하세요). 동영상이 정상 재생되는 상태를 유지하세요. DRM / 유료 동영상은 검게 나옵니다(브라우저 보호 제한).
2. 확장 아이콘을 클릭 → 팝업의 **녹화 시작**을 클릭합니다(탭을 보이는 상태로 유지하고 플레이어가 뷰포트 안에 완전히 들어오게 하세요).
   - 브라우저 / OS가 네이티브 MP4를 지원하지 않으면(Chrome < 126 또는 H.264/AAC 인코더 부족) 팝업 하단에 이번 세션은 WebM으로 대체된다는 안내가 표시됩니다.
   - 녹화 중에는 아이콘에 빨간 `REC` 배지가 표시됩니다. 팝업을 닫아도 녹화는 계속되며, 아이콘을 다시 클릭하면 조작할 수 있습니다.
3. **영역 녹화**(선택)：「**영역 녹화**」클릭 → 팝업이 자동으로 닫힘 → 페이지에서 사각형을 드래그 →「선택 영역 녹화」클릭(`Esc`로 선택 모드 종료).
   - 녹화 중「정지」버튼은 **선택 영역 바깥**에 자동 배치되어 영상에 절대 잡히지 않습니다. 선택 영역이 뷰포트를 거의 가득 채워 둘 곳이 없으면 페이지 내 컨트롤이 숨겨지니, 확장 팝업이나 단축키로 정지하세요.
4. 종료 시「**정지 후 저장**」클릭 → 자동으로 조립되어 `사이트명-년월일-시분초.mp4`로 다운로드됩니다(접두사는 사이트별로 자동 전환. 예: `YouTube-20240908-153000.mp4`, `Bilibili-20240908-153000.mp4`. 폴백 환경에서는 `.webm`).
5. **단축키**: 지원 사이트의 동영상 페이지에서 기본 키 `R`을 누르면 녹화가 시작되고, 녹화 중 다시 누르면 정지 후 저장됩니다.
   - 팝업 오른쪽 위의「**설정**」에서 변경할 수 있습니다. 키 입력란을 클릭한 뒤 새 조합을 누르고, `Esc`로 취소. 변경은 즉시 반영되며 페이지 새로고침은 필요 없습니다.
   - 단축키는 지원 사이트의 동영상 페이지에 포커스가 있을 때만 동작하며 검색창 / 댓글창 같은 입력 영역에서는 발동하지 않습니다. 브라우저나 사이트 플레이어 단축키와 충돌하면 설정 패널에 경고가 표시됩니다.
6. **화면 미세 조정**(팝업 하단 접이식 항목): 드문 환경(특이한 줌 조합, DPI가 다른 멀티 모니터 등)에서는 크롭에 고정 오차가 남을 수 있습니다. 이때「세로 / 가로」에 픽셀 값을 입력해 크롭 박스를 이동합니다(양수 = 아래 / 오른쪽).
7. **녹화 중에는 페이지가 마스크로 잠깁니다**(플레이어 전체 모드):
   - 영상 바깥이 반투명 검정으로 덮여 버튼과 링크를 클릭할 수 없고, 휠·터치 스크롤이 차단되며 스크롤 위치가 고정됩니다.
   - **사용 가능**: 재생/일시정지, 탐색, 볼륨, 자막, 재생 속도 등 순수 재생 조작.
   - **차단**: 스크롤/페이지 넘김 키(Space, PageUp/PageDown, Home/End, 상하 방향키), 전체 화면 `f`, 극장 모드 `t`, 미니플레이어 `i`, 음소거 `m`, 영상 더블클릭 — 레이아웃을 바꾸거나 오디오 트랙을 무음으로 만드는 동작입니다.
   - 마스크는 영상 부분만 구멍을 뚫으므로 녹화 대상을 덮지 않아 **출력 영상에 절대 나타나지 않습니다**. 영상 아래(공간이 없으면 위)에 "녹화 중 · 페이지 잠김"이 표시됩니다.
   - 브라우저 창 크기 조절은 웹페이지가 막을 수 없습니다. 뷰포트 크기 변화가 감지되면 마스크 위에 경고가 표시되고 팝업에서 재녹화를 안내합니다(이때 크롭이 어긋났을 수 있음).
8. 정지 후 마스크는 자동으로 제거되며 페이지는 원래 상태로 돌아갑니다(잔여 노드·리스너 없음).

### 출력 형식

| 환경 | 출력 형식 |
| --- | --- |
| Chrome 126 이상 + H.264/AAC 인코더(Windows / macOS 최신 Chrome 등) | **MP4**(H.264 + AAC, `.mp4`) |
| Chrome 126 미만 | WebM(`.webm`). 팝업에 폴백 사유가 표시됩니다 |
| Chrome 126 이상이지만 플랫폼에 인코더 없음(일부 Linux 빌드 등) | WebM(`.webm`). 팝업에 폴백 사유가 표시됩니다 |

> 재인코딩은 전혀 하지 않습니다. MP4가 가능하면 `MediaRecorder`가 네이티브로 녹화하고(대기 시간 0, 화질 손실 없음), 불가능할 때만 WebM으로 대체합니다.

### 권한

| 권한 | 용도 |
| --- | --- |
| `tabCapture` | 제한 권한. 사용자 클릭 후 현재 탭의 영상과 오디오를 캡처합니다 |
| `downloads` | 녹화 결과를 로컬 다운로드 폴더에 저장합니다 |
| `activeTab` | 확장 아이콘 클릭 시 현재 탭에 대한 임시 접근 권한을 부여합니다 |
| `offscreen` | 캡처 / 크롭 / 녹화를 담당하는 오프스크린 문서를 생성합니다 |
| `storage` | `session`에 녹화 상태와 시작 의도, `sync`에 단축키·화면 미세 조정·전체 화면 녹화 상태 표시 스위치를 저장합니다 |
| `notifications` | 전체 화면 녹화 상태 표시: 녹화 중 상주하는 "녹화 중" 알림(정지 버튼 포함) + 저장 성공 / 실패 1회성 알림(설정에서 끌 수 있음) |

`host_permissions` 없음, 네트워크 요청 없음, 사용자 데이터 수집 없음. content 스크립트는 `content_scripts.matches`에 지정된 위 7개 지원 사이트 도메인에서만 주입·동작하며, 다른 사이트에서는 스크립트 주입이나 어떤 동작도 일어나지 않습니다.
