Chrome Manifest V3 확장 프로그램입니다. YouTube 재생 페이지에서 **직접 클릭**하여 녹화를 시작하면, 탭 전체 화면과 페이지 오디오를 캡처하고 브라우저 내부에서 Canvas로 프레임 단위로 **플레이어 영역(또는 직접 드래그해서 선택한 영역)**을 잘라낸 뒤, 최종적으로 **오디오가 포함된 동영상 파일**을 로컬에 다운로드합니다. 기본적으로 **MP4(H.264/AAC)**를 네이티브로 우선하며, 브라우저나 OS가 지원하지 않으면 자동으로 **WebM**으로 대체합니다.

## 주요 기능

- **서드파티 의존성 Zero**: npm 없음, 빌드 단계 없음, ffmpeg 없음, 재인코딩 전혀 없음(MP4는 `MediaRecorder`가 네이티브로 녹화하며, 녹화 후 변환하지 않습니다).
- **두 가지 녹화 모드**
  - **플레이어 전체**: `object-fit` / `object-position`을 계산해 플레이어의 *실제로 그려지는* 사각형을 자동으로 찾아 레터박스, 극장 모드 여백, 플레이어 외곽을 제외합니다.
  - **영역 선택**: 페이지에서 원하는 사각형을 드래그하여 그 영역만 녹화합니다.
- **항상 깨끗한 화면**: 모든 컨트롤은 확장 프로그램 아이콘 팝업(캡처 대상 탭의 렌더링에 포함되지 않는 독립된 확장 페이지)에 있으므로 확장 UI가 영상에 절대 등장하지 않습니다.
- **페이지 단축키**: 기본 단일 키 `R`은 대기 중일 때 녹화를 시작하고, 녹화 중에는 정지 후 저장합니다. 팝업 → **설정**에서 `Ctrl` / `Alt` / `Shift` / `Command` 조합으로 자유롭게 변경할 수 있습니다. YouTube 페이지에서만 동작하며 다른 탭의 키를 가로채거나 브라우저 전역 단축키와 충돌하지 않습니다.
- **녹화 중 페이지 잠금**: 반투명 마스크가 이미지 *바깥* 전체를 덮고(이미지 부분만 "구멍"을 냄) 스크롤, 클릭, 파괴적인 단축키를 차단합니다. 반면 **재생/일시정지, 탐색, 볼륨, 자막, 재생 속도는 그대로 사용할 수 있습니다**.
- **안정적인 크롭**: 30fps 고정 출력, 캔버스 크기는 첫 프레임에서 고정, 크롭 사각형이 3프레임 연속 안정된 뒤에야 녹화를 시작하므로 광고나 극장 모드 전환 시의 일시적으로 커진 사각형이 영상에 남지 않습니다.
- **오디오 손실 없음**: 캡처한 오디오 트랙을 `AudioContext`로 재생하여 탭이 음소거되어 무음 영상이 되는 것을 방지합니다.
- **충실한 예외 처리**: DRM 블랙 프레임 감지, 탭 전환/페이지 이동 시 자동 정지 후 내보내기, 사각형 하트비트 중단 시 자가 복구, 다운로드 실패 자동 재시도, 잔여 세션을 위한 "강제 초기화 후 다시 시작" 탈출구.
- **녹화는 오직 사용자 클릭으로만 시작**되며, 백그라운드 몰래 캡처는 절대 없습니다.

## 아키텍처 (왜 offscreen document가 필요한가)

`chrome.tabCapture`는 content script에서 호출할 수 없고, 크롭에 필요한 `video` / `canvas` / `MediaRecorder`는 DOM이 있는 윈도우 컨텍스트에서 동작해야 합니다. 팝업은 포커스를 잃으면 닫히고 Service Worker에는 DOM이 없으므로, 녹화 코어는 **offscreen document**에 있습니다.

1. **content script**(자체 UI를 주입하지 않고 데이터만 보고함)가 약 120ms마다 플레이어를 찾아 실제 이미지 사각형과 뷰포트 기준(CSS 크기, `devicePixelRatio`, visual viewport 오프셋)을 보고합니다.
2. **background**가 필요할 때 오프스크린 문서를 만들고 사용자 제스처 체인 안에서 `chrome.tabCapture.getMediaStreamId()`를 호출해 `streamId`를 얻습니다.
3. **오프스크린** 문서가 `getUserMedia({ chromeMediaSourceId: streamId })`로 탭 전체 스트림(영상 + 페이지 오디오)을 소비합니다.
4. **오프스크린** 내부: 숨은 `video`가 탭 스트림을 재생 → 숨은 `canvas`가 `drawImage`로 프레임마다 크롭 → `canvas.captureStream(30)` 비디오 트랙과 원본 `audioTrack`을 합성 → `MediaRecorder`가 녹화(`video/mp4` 우선, 단계적으로 `video/webm`으로 폴백) → 청크를 Blob으로 조립합니다.
   - 좌표 변환은 단순한 `rect × devicePixelRatio`가 아니라 **실측 비율**(「캡처 프레임 크기 ÷ 뷰포트 CSS 크기」, contain 모델 + 중앙 패딩)을 사용하므로 HiDPI나 확대 환경에서도 어긋남이 없습니다.
5. 오프스크린 문서는 `chrome.downloads`를 직접 호출할 수 **없으므로** `DOWNLOAD_FILE` 메시지를 **background**에 보내 대신 다운로드하게 하고, `downloads.onChanged`로 결과를 돌려받습니다.

자세한 내용은 `DESIGN.md`를 참고하세요.

## 로드하기 (개발/디버그)

1. Chrome을 열고 `chrome://extensions`로 이동합니다.
2. 오른쪽 상단에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 이 저장소의 `src/` 디렉터리를 선택합니다(빌드 단계 없음, 컴파일 불필요).

> 요구 사항: Chrome 116 이상(`minimum_chrome_version`, `chrome.offscreen`에 필요). 네이티브 MP4 출력은 Chrome 126 이상이 필요합니다. 최신 안정 버전을 권장합니다.

## 사용법

1. 아무 **YouTube 재생 페이지**나 엽니다(공개 영상에 한함. DRM/멤버십 전용 영상은 검은 화면으로 녹화됩니다 — 브라우저 보호 제한입니다).
2. 확장 아이콘을 클릭 → 팝업에서 **녹화 시작**을 클릭합니다(탭을 보이는 상태로 유지하고 플레이어가 뷰포트 안에 완전히 들어오게 하세요).
   - 브라우저/OS가 네이티브 MP4를 만들 수 없는 경우(Chrome < 126 또는 H.264/AAC 인코더 부재), 팝업 하단에 WebM으로 대체된다고 안내합니다.
   - 녹화 중에는 아이콘에 빨간 `REC` 배지가 표시됩니다. 팝업을 닫아도 녹화는 계속되며, 아이콘을 다시 클릭하면 조작할 수 있습니다.
3. **영역 녹화**(선택): **영역 녹화** 클릭 → 팝업이 자동으로 닫힘 → 페이지에서 사각형을 드래그 → **선택 영역 녹화** 클릭(`Esc`로 선택기 종료).
   - 녹화 중 **정지** 버튼은 선택 영역 *바깥*에 자동 배치되어 영상에 절대 찍히지 않습니다. 선택 영역이 뷰포트를 거의 채워 자리가 없으면 페이지 내 컨트롤을 숨깁니다. 이때는 확장 팝업이나 단축키로 정지하세요.
4. 종료할 때 **정지하고 저장**을 클릭 → 자동으로 조립되어 `YouTube-연월일-시분초.mp4`(폴백 환경에서는 `.webm`)로 다운로드됩니다.
5. **단축키**: YouTube 재생 페이지에서 기본 키 `R`을 누르면 녹화를 시작하고, 녹화 중에 다시 누르면 정지 후 저장합니다.
   - 팝업 오른쪽 상단의 **설정**에서 변경할 수 있습니다. 키 상자를 클릭한 뒤 새 조합을 누르고, `Esc`로 취소합니다. 변경 즉시 적용되며 페이지 새로고침이 필요 없습니다.
   - 단축키는 YouTube 페이지에 포커스가 있을 때만 동작하며 검색창/댓글창 등 입력 영역에서는 실행되지 않습니다. 브라우저 또는 YouTube 플레이어 단축키와 충돌하면 설정 패널에 경고가 표시됩니다.
6. **화면 미세 조정**(팝업 하단 접힌 항목): 드문 환경(특이한 확대 조합, 서로 다른 DPI 모니터 혼용)에서는 고정 오차가 남을 수 있습니다. 이때 "수직 / 수평" 픽셀 값을 입력해 크롭 박스를 이동시킵니다(양수 = 아래 / 오른쪽).
7. **녹화 중에는 페이지가 마스크로 잠깁니다**(플레이어 전체 모드):
   - 이미지 바깥 전체가 반투명 검정으로 덮여 버튼과 링크를 클릭할 수 없고, 휠/터치 스크롤이 차단되며 스크롤 위치가 고정됩니다.
   - **사용 가능**: 재생/일시정지, 탐색, 볼륨, 자막, 재생 속도 등 순수한 재생 제어.
   - **차단**: 스크롤/페이지 이동 키(스페이스, PageUp/Down, Home/End, 위/아래 화살표), 전체 화면 `f`, 극장 모드 `t`, 미니 플레이어 `i`, 음소거 `m`, 이미지 더블클릭 — 레이아웃을 바꾸거나 오디오 트랙을 무음으로 만드는 동작입니다.
   - 마스크는 이미지에 맞춰 구멍을 내므로 녹화되는 부분을 덮지 않아 **출력 영상에 절대 나타나지 않습니다**. 이미지 아래(공간이 부족하면 위)에 "녹화 중 · 페이지가 잠겼습니다"가 표시됩니다.
   - 브라우저 창 크기 조정은 웹페이지가 막을 수 없습니다. 뷰포트 크기 변화가 감지되면 마스크에 경고가 표시되고 팝업에 재녹화 권장 안내가 뜹니다(이때 크롭이 어긋났을 수 있습니다).
8. 정지 후에는 마스크가 자동으로 제거되고 페이지가 원래대로 돌아오며, 남는 노드나 리스너가 없습니다.

### 출력 형식

| 환경 | 출력 |
| --- | --- |
| Chrome 126 이상 + H.264/AAC 인코더 있음(예: Windows/macOS 최신 Chrome) | **MP4**(H.264 + AAC, `.mp4`) |
| Chrome 126 미만 | WebM(`.webm`) — 팝업에 폴백 이유 안내 |
| Chrome 126 이상이나 인코더가 없는 플랫폼(일부 Linux 빌드) | WebM(`.webm`) — 팝업에 폴백 이유 안내 |

> 재인코딩은 전혀 하지 않습니다. MP4가 가능하면 `MediaRecorder`가 네이티브로 녹화하여(대기 없음, 화질 손실 없음) 출력하고, 불가능할 때만 WebM으로 폴백합니다.

### 권한

| 권한 | 용도 |
| --- | --- |
| `tabCapture` | 제한 권한. 사용자 클릭 후 현재 탭의 화면과 소리를 캡처합니다 |
| `downloads` | 녹화 결과를 로컬 다운로드 폴더에 저장합니다 |
| `activeTab` | 확장 아이콘 클릭 시 현재 탭에 대한 임시 접근 권한 |
| `offscreen` | 캡처 / 크롭 / 녹화를 담당할 오프스크린 문서를 생성합니다 |
| `storage` | `session`에 녹화 상태와 시작 의도, `sync`에 단축키와 화면 미세 조정 값을 저장합니다 |

`host_permissions` 없음, 네트워크 요청 없음, 사용자 데이터 수집 없음.

## 정적 자체 검사

```bash
python3 scripts/verify_extension.py
```

검사 항목: 매니페스트 / MV3 / 필수 파일, YouTube 도메인 한정과 주입 순서, 최소 권한, 서드파티 의존성 없음, 모든 JS 문법(`node --check`), API 컨텍스트 경계(content script가 `tabCapture` / `downloads` / `offscreen`를 직접 호출하지 않음), 페이지 주입 경계(컨트롤은 확장 팝업에 있어야 하며, 페이지에서 DOM 생성이 허용되는 유일한 모듈인 `content/guard.js`는 이미지 사각형에 맞춰 구멍을 내고 그 안을 비우며 세션마다 제거 가능해야 함), 단축키 모듈 경계.

- [ ] 20.3 출력 파일을 시스템 플레이어나 Chrome으로 연다: 화면이 플레이어 영역으로 크롭되어 있고, 오디오가 있으며, 정상 재생된다.
- [ ] 20.4 고해상도 화면(DPR ≠ 1, 예: Retina)에서 화면이 밀리거나 어긋나지 않는다.
- [ ] 20.5 녹화 중 탭 전환: 팝업에 캡처가 중단될 수 있다는 안내가 뜬다. 돌아오면 녹화가 계속되거나 자동 정지 후 내보내지며 이상이 없다.
- [ ] 20.6 녹화 중 전체 화면 전환 / 브라우저 확대: 크롭 영역이 정확히 따라온다.
- [ ] 20.7 오류 상황 안내가 정확하다: 재생 페이지가 아님(시작 버튼 비활성), DRM 영상(약 2.6초 후 팝업 안내), 캡처 거부 등.
- [ ] 20.8 녹화 종료 후(예외 포함): 주소창에 녹화 빨간 점이 없고, 페이지에 확장 잔여 노드가 없으며, 지속적인 오류가 없다.
- [ ] 20.9 Chrome 126 미만 또는 H.264/AAC 인코더가 없는 플랫폼에서 "네이티브 MP4 미지원으로 WebM 출력" 안내가 뜨고 녹화/다운로드는 정상 동작한다.
- [ ] 20.10 출력 영상에 확장 컨트롤이 전혀 없다(버튼 / 모달 / 토스트 없음).
- [ ] 20.11 출력 영상에 잠금 마스크가 없다(가장자리 검은 띠 없음, 안내 문구 없음).
- [ ] 20.12 녹화 중 페이지가 마스크로 잠긴다: 버튼 / 링크를 클릭할 수 없고, 휠과 단축키가 무효하며 페이지가 스크롤되지 않는다. 단, 재생/일시정지, 탐색, 볼륨 등 재생 제어는 동작한다.
- [ ] 20.13 녹화 중 창 크기 조절: 마스크에 경고 + 팝업 안내, 마스크가 구멍을 다시 내도 이미지를 덮지 않는다.
