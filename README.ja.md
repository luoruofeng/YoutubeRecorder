Chrome Manifest V3 拡張機能です。**YouTube、Bilibili（ビリビリ）、Dailymotion、Vimeo、Instagram、Facebook、TikTok** など対応サイトの動画ページで**手動クリック**して録画を開始すると、タブ全体の画面とページ音声をキャプチャし、ブラウザ内で Canvas によりフレームごとに**プレーヤーの実際の映像領域（またはドラッグで選択した任意の領域）**を切り抜き、最終的に**音声付きの動画ファイル**をローカルにダウンロードします。ネイティブでは **MP4（H.264/AAC）** を優先し、ブラウザや OS が対応しない場合は自動的に **WebM** へフォールバックします。

録画対象サイトは自動認識されます。拡張機能は現在のページのドメインからサイトを判定し、出力ファイル名のプレフィックスとポップアップ / 通知内のサイト表記を自動的に切り替えます（下記「対応サイト」参照）。

## 特徴

- **7 大動画サイトをまとめて録画**：YouTube / Bilibili（B 站） / Dailymotion / Vimeo / Instagram / Facebook / TikTok の公式ネイティブ動画ページをすべて同じパイプライン（tabCapture → プレーヤー特定 → Canvas 切り抜き → MediaRecorder）で録画できます。現在のサイトを自動認識してファイル名プレフィックスとサイト表記を切り替え、各サイトの新旧プレーヤーレイアウト差異は `src/shared/sites.js` に集約して一元管理します（下記「対応サイト」参照）。
- **サードパーティ依存ゼロ**：npm なし、ビルド不要、ffmpeg 不要、再エンコード一切なし（MP4 は `MediaRecorder` がネイティブに録画し、録画後の変換は行いません）。
- **2 つの録画モード**
  - **プレーヤー全体**：`object-fit` / `object-position` からプレーヤーの「実際に描画されている矩形」を自動算出し、黒帯・シアターモードの余白・プレーヤー外枠を除外して映像本体のみを録画します。
  - **範囲選択**：ページ上で矩形をドラッグ選択し、その領域だけを録画します。
- **映像が常にクリーン**：録画コントロールはすべて拡張機能アイコンのポップアップ（キャプチャ対象タブの描画内容に含まれない独立した拡張ページ）にあるため、拡張 UI が動画に映り込むことはありません。
- **ページショートカット**：既定の単一キー `R` で、待機中は録画開始、録画中は停止して保存します。ポップアップの「**設定**」から `Ctrl` / `Alt` / `Shift` / `Command` の組み合わせに自由に変更できます。対応サイトの動画ページでのみ有効で、他のタブのキーを奪ったりブラウザのグローバルショートカットと衝突したりしません。
- **録画中のページロック**：半透明マスクが映像の外側を覆い（映像部分だけ「穴」を開ける）、スクロール・クリック・破壊的なショートカットを遮断します。一方で**再生 / 一時停止・シーク・音量・字幕・再生速度などの純粋な再生操作はそのまま使えます**。
- **安定した切り抜き**：出力は固定 30fps。キャンバスサイズは最初のフレームで固定。切り抜き矩形が 3 フレーム連続して安定するまで録画を開始しないため、広告やシアターモード遷移時の一時的な大きな矩形が動画に残りません。
- **音声を取りこぼさない**：キャプチャした音声トラックを `AudioContext` で再生し、録画中にタブがミュートされて無音になるのを防ぎます。
- **フルスクリーンでも「録画中」が見える**：フルスクリーン再生中は画面が埋まり、マスクの案内を置く場所がないため、常駐システム通知と最前面の Document PiP ステータス窓（REC + タイマー + 停止ボタン）で状態を表示します。映像に黒帯がある場合は黒帯内に細い赤枠も描画します。すべてのインジケーターはキャプチャ対象の映像の外側にあり、**動画には入りません**。ポップアップの「**設定 → 全画面録画ステータス表示**」で個別に ON / OFF できます。
- **異常時のフォールバックが充実**：DRM の黒画面検出、タブ切り替え / ページ遷移時の自動停止と書き出し、矩形ハートビート途絶時の自己復旧、ダウンロード失敗の自動リトライ、残留セッションの「強制リセットして再開」。
- **録画は必ずユーザーのクリックで開始**され、バックグラウンドでの暗中キャプチャは一切行いません。

## 対応サイト

録画パイプライン（tabCapture → プレーヤー特定 → Canvas 切り抜き → MediaRecorder）は全サイトで完全に同一で、違いは次の 3 点のみです：**注入ドメイン**（`manifest.json` の `content_scripts.matches`）、**プレーヤー特定に使う DOM セレクター**、そして**ファイル名プレフィックス / 表記に使うサイト名**。下表が現在対応しているサイトと適用ページです：

| サイト | 録画できるページ形態 | 説明と制限 |
| --- | --- | --- |
| YouTube | 動画再生ページ（`youtube.com/watch…`、Shorts など） | メンバー限定 / 有料 / DRM 映像は黒画面になります（ブラウザ保護。下記の共通制限を参照） |
| Bilibili（B 站） | 動画再生ページ（`bilibili.com/video/BV…`） | 新版 bpx と旧版 bilibili プレーヤーの両方に対応。大会員 / DRM 制限のある番組・映画は黒画面になる可能性あり。**ライブ配信は対象外** |
| Dailymotion | 動画再生ページ（`dailymotion.com/video/…`） | プレーヤーの `<video>` がクロスオリジン iframe / shadow DOM で包まれている場合（メインドキュメントから読めない）は、プレーヤー外殻コンテナ矩形の特定に自動フォールバック |
| Vimeo | 動画再生ページ（`vimeo.com/…`） | プライベート動画はログインと閲覧権限が必要 |
| Instagram | 投稿 / Reel / ストーリー（開いたモーダル表示）、ホームフィード内の単体動画 | 一部コンテンツはログインしないと再生可能な動画がない |
| Facebook | Watch / Reel / 単体動画のオーバーレイ / タイムライン内の動画 | 一部コンテンツはログインが必要。タイムラインに複数動画がある場合は「現在表示中のメイン動画」を自動ヒット |
| TikTok | 動画詳細ページ（`tiktok.com/@…/video/…`）、開いた動画オーバーレイ、For You フィード内の単体動画 | フィード内に複数プレビューがある場合は「再生中 / 表示面積が最大」のものを自動ヒット |

> **特定メカニズム**：content スクリプトはページ内で「実際に見えている `<video>`」をもとに録画領域を特定します。`src/shared/sites.js` が各サイトの新旧レイアウトのプレーヤーコンテナ / video 候補セレクターを一元管理し、コンテナにヒットしたらその内側の `<video>` を取得し、`object-fit` / `object-position` から実際に描画されている映像矩形を換算します（黒帯・外殻・余白を除外）。全候補が外れた場合は、「表示面積が最大のデコード済み `<video>`」を汎用フォールバックとします（open shadow DOM を再帰的にカバー）。したがって、メインドキュメント（または読める open shadow root）に本物の `<video>` が描画されている必要があります。**他のウェブページからクロスオリジン iframe で埋め込まれたプレーヤーは対象外**。純粋な canvas / WebGL など `<video>` 以外で自前描画している画面は自動特定できないため、**「範囲選択」** をお使いください。

> **共通制限**：
> - DRM / 会員有料で保護された動画（各プラットフォームの有料映画、サブスク限定、独占ライセンス作品など）はキャプチャ画面で黒画面になります。これはブラウザの「保護コンテンツ」制限であり、拡張機能の不具合ではありません。
> - ログインが必要なコンテンツ（Instagram / Facebook / TikTok の大部分の動画、B 站の一部の番組など）は、事前にブラウザで該当サイトにログインしてください。
> - サイト改版でセレクターがずれ、画面内に複数の見える `<video>` がある場合、録画領域は既定で「表示面積が最大でデコード中のもの」を取ります。対象動画をビューポート内で再生状態にしておいてください。

## アーキテクチャ（なぜ offscreen document が必要か）

`chrome.tabCapture` は content script から呼べません。一方、切り抜きに必要な `video` / `canvas` / `MediaRecorder` は DOM を持つウィンドウコンテキストで動かす必要があります。ポップアップはフォーカスを失うと閉じ、Service Worker には DOM がありません。そこで録画の中核は **offscreen document** に置きます。

1. **content script**（自身は UI を注入せずデータ送信のみ）が対応ページ内でプレーヤーを特定し（`shared/sites.js` で識別）、約 120ms ごとに「実際の映像矩形」とビューポート基準（CSS サイズ / `devicePixelRatio` / visualViewport のオフセット）を送信します。
2. **background** がオンデマンドでオフスクリーンドキュメントを作成し、ユーザージェスチャーの流れの中で `chrome.tabCapture.getMediaStreamId()` を呼び出して `streamId` を取得します。
3. **オフスクリーン**が `getUserMedia({ chromeMediaSourceId: streamId })` でタブ全体のストリーム（映像 + ページ音声）を消費します。
4. **オフスクリーン**内で処理：隠し `video` がタブストリームを再生 → 隠し `canvas` が `drawImage` でフレームごとに切り抜き → `canvas.captureStream(30)` の映像トラックと元の `audioTrack` を合成 → `MediaRecorder` が録画（`video/mp4` を優先し、順次 `video/webm` へフォールバック）→ Blob を組み立てます。
   - 座標変換は `rect × devicePixelRatio` のような単純計算ではなく、**実測比率**（「キャプチャフレームサイズ ÷ ビューポート CSS サイズ」を contain モデルと中央パディングで補正）を使うため、高 DPI やズーム環境でもズレが発生しません。
5. オフスクリーンは `chrome.downloads` を直接呼べないため、`DOWNLOAD_FILE` メッセージで **background** に代行させ、`downloads.onChanged` で結果を受け取ります。

詳細は `DESIGN.md` を参照してください。

## 読み込み（開発・デバッグ）

1. Chrome で `chrome://extensions` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このリポジトリの `src/` ディレクトリを選択します（ビルド不要・コンパイル不要）。

> 要件：Chrome 116 以上（`minimum_chrome_version`。`chrome.offscreen` に必要）。ネイティブ MP4 出力には Chrome 126 以上が必要です。最新の安定版を推奨します。

## 使い方

1. 対応サイトの動画ページを開きます（上記「対応サイト」参照。例：YouTube の再生ページ、B 站の `video/BV…` ページ、TikTok の動画詳細ページなど。初回アクセス時はスクリプト注入のため一度リフレッシュしてください）。動画が正常に再生される状態を保ってください。DRM / 会員有料動画は黒画面になります（ブラウザ保護制限）。
2. 拡張機能アイコンをクリック → ポップアップで「**録画開始**」をクリックします（タブを表示状態に保ち、プレーヤーがビューポート内に完全に収まるようにしてください）。
   - ブラウザ / OS がネイティブ MP4 に対応していない場合（Chrome < 126、または H.264/AAC エンコーダー不足）、ポップアップ下部に WebM へフォールバックする旨が表示されます。
   - 録画中はアイコンに赤い `REC` バッジが表示されます。ポップアップを閉じても録画は継続し、アイコンを再度クリックすれば操作できます。
3. **範囲録画**（任意）：「**範囲録画**」をクリック → ポップアップが自動で閉じる → ページ上で矩形をドラッグ → 「選択範囲を録画」をクリックします（`Esc` で選択モードを終了）。
   - 録画中の「停止」ボタンは**選択範囲の外側**に自動配置されるため、動画に映り込みません。選択範囲がビューポートいっぱいで置き場所がない場合はページ内コントロールを隠します。その際は拡張機能のポップアップまたはショートカットで停止してください。
4. 終了時に「**停止して保存**」をクリック → 自動的に組み立てられ `サイト名-年月日-時分秒.mp4` としてダウンロードされます（プレフィックスはサイトごとに自動切替。例：`YouTube-20240908-153000.mp4`、`Bilibili-20240908-153000.mp4`。フォールバック環境では `.webm`）。
5. **ショートカット**：対応サイトの動画ページで既定キー `R` を押すと録画開始、録画中にもう一度押すと停止して保存します。
   - ポップアップ右上の「**設定**」で変更できます。キーボックス内をクリックして新しい組み合わせを押し、`Esc` でキャンセル。変更は即時反映され、ページの再読み込みは不要です。
   - ショートカットは対応サイトの動画ページにフォーカスがあるときのみ有効で、検索欄 / コメント欄などの入力欄では発火しません。ブラウザやサイトのプレーヤーショートカットと競合する場合は設定パネルに警告が出ます。
6. **映像の微調整**（ポップアップ下部の折りたたみ項目）：まれな環境（特殊なズーム組み合わせ、異なる DPI のマルチモニターなど）では切り抜きに固定ズレが残ることがあります。その場合は「垂直 / 水平」にピクセル値を入力してクロップ枠を移動させます（正の値 = 下 / 右）。
7. **録画中はページがマスクでロックされます**（プレーヤー全体モード）：
   - 映像の外側が半透明の黒で覆われ、ボタンやリンクをクリックできず、ホイールやタッチスクロールも遮断され、スクロール位置が固定されます。
   - **操作可能**：再生 / 一時停止、シーク、音量、字幕、再生速度など純粋な再生操作。
   - **遮断**：スクロール / ページ送りキー（Space、PageUp / PageDown、Home / End、上下矢印）、全画面 `f`、シアターモード `t`、ミニプレーヤー `i`、ミュート `m`、映像のダブルクリック —— レイアウトが変わる、または音声トラックが無音になる操作です。
   - マスクは映像部分に穴を開けているため録画対象を覆わず、**出力動画に映り込みません**。映像の下（空きがない場合は上）に「録画中 · ページはロックされています」と表示されます。
   - ブラウザウィンドウのリサイズは Web ページから禁止できません。ビューポートサイズの変化を検出すると、マスク上に警告を表示し、ポップアップで再録画を案内します（この場合クロップがズレている可能性があります）。
8. 停止後はマスクが自動的に削除され、ページは元の状態に戻ります（残留ノード・リスナーなし）。

### 出力フォーマット

| 環境 | 出力形式 |
| --- | --- |
| Chrome 126 以上 かつ H.264/AAC エンコーダーあり（Windows / macOS の新しい Chrome など） | **MP4**（H.264 + AAC、`.mp4`） |
| Chrome 126 未満 | WebM（`.webm`）。ポップアップにフォールバック理由が表示されます |
| Chrome 126 以上だがプラットフォームにエンコーダーがない（一部の Linux ビルドなど） | WebM（`.webm`）。ポップアップにフォールバック理由が表示されます |

> 再エンコードは一切行いません。MP4 が可能な場合は `MediaRecorder` がネイティブに録画し（待ち時間ゼロ・画質劣化なし）、不可の場合のみ WebM にフォールバックします。

### 権限

| 権限 | 用途 |
| --- | --- |
| `tabCapture` | 制限付き権限。ユーザークリック後に現在のタブの映像と音声をキャプチャします |
| `downloads` | 録画結果をローカルのダウンロードフォルダに保存します |
| `activeTab` | 拡張機能アイコンクリック時に現在のタブへの一時的なアクセス権を付与します |
| `offscreen` | キャプチャ / 切り抜き / 録画を担うオフスクリーンドキュメントを作成します |
| `storage` | `session` に録画状態と開始インテント、`sync` にショートカット・映像微調整・全画面録画ステータス表示スイッチを保存します |
| `notifications` | 全画面録画ステータス表示：録画中に常駐する「録画中」通知（停止ボタン付き）+ 保存成功 / 失敗の一度きり通知（設定で OFF 可） |

`host_permissions` なし、ネットワークリクエストなし、ユーザーデータの収集なし。content スクリプトは `content_scripts.matches` で指定した上記 7 サイトのドメイン下でのみ注入・動作し、他のサイトではスクリプト注入も動作も一切行われません。

```bash
python3 scripts/verify_extension.py
```

チェック内容：マニフェスト / MV3 / 必須ファイル、対応サイト（YouTube / Bilibili / Dailymotion / Vimeo / Instagram / Facebook / TikTok）のドメイン限定と注入順（`shared/hotkey.js` → `shared/indicator.js` → `shared/sites.js` → `content/guard.js` → `content/pip.js` → `content/selector.js` → `content/countdown.js` → `content/content.js` → `content/hotkey.js`）、最小権限、サードパーティ依存ゼロ、全 JS の構文（`node --check`）、API コンテキスト境界（content script が `tabCapture` / `downloads` / `offscreen` を直接呼ばない）、ページ注入境界（コントロールは拡張ポップアップに置くこと。ページで DOM 生成が許されるのは `content/guard.js` のみで、映像矩形に穴を開け、穴内を空にし、セッションごとに削除できること）、ショートカットモジュールの境界。
