Расширение Chrome Manifest V3: на странице просмотра YouTube **ручной клик** запускает запись. Расширение захватывает всю поверхность вкладки вместе со звуком страницы, кадр за кадром вырезает с помощью Canvas **область плеера (или любую выделенную вами область)** и в итоге сохраняет **видеофайл со звуком** в папку загрузок — нативно предпочитает **MP4 (H.264/AAC)**, автоматически откатываясь на **WebM**, если браузер или система это не поддерживают.

## Возможности

- **Ноль сторонних зависимостей**: никакого npm, никакой сборки, никакого ffmpeg, никакого перекодирования (MP4 записывается нативно через `MediaRecorder`, а не конвертируется после записи).
- **Два режима записи**
  - **Весь плеер**: автоматически определяется *фактически отрисовываемый* прямоугольник плеера (рассчитывается по `object-fit` / `object-position`), исключая чёрные полосы, поля театрального режима и оболочку плеера.
  - **Выделение области**: выделите прямоугольник в любом месте страницы и записывайте только его.
- **Абсолютно чистая картинка**: все элементы управления находятся во всплывающем окне значка расширения (отдельная страница расширения, не входящая в отрисовку захватываемой вкладки), поэтому интерфейс расширения никогда не попадёт в видео.
- **Горячая клавиша на странице**: по умолчанию одиночная клавиша `R` запускает запись в режиме ожидания и останавливает/сохраняет её во время записи. Меняется в окне → **Настройки** (поддерживаются комбинации с `Ctrl` / `Alt` / `Shift` / `Command`). Работает только на страницах YouTube, не перехватывает клавиши других вкладок и не конфликтует с глобальными сочетаниями браузера.
- **Страница блокируется на время записи**: полупрозрачная маска закрывает всё *вне* картинки, вырезая для неё «отверстие», блокируя прокрутку, клики и разрушительные горячие клавиши — при этом **воспроизведение/пауза, перемотка, громкость, субтитры и скорость воспроизведения остаются полностью доступными**.
- **Стабильная обрезка**: фиксированные 30 кадров/с; размер canvas фиксируется на первом кадре; прямоугольник обрезки должен оставаться неизменным 3 кадра подряд до старта записи, чтобы случайно увеличенные прямоугольники (реклама, переход в театральный режим) не попали в итоговое видео.
- **Звук не теряется**: захваченная аудиодорожка воспроизводится через `AudioContext`, не давая вкладке уйти в беззвучный режим и не создавая видео без звука.
- **Полный набор страховок**: обнаружение чёрного кадра DRM, автоматическая остановка и экспорт при переключении вкладки или переходе, самовосстановление при сбое heartbeat прямоугольника, автоматический повтор загрузки и аварийный выход «Сбросить и начать заново».
- **Запись запускается только кликом пользователя** — никакой скрытой фоновой записи, никогда.

## Зачем нужен offscreen-документ?

`chrome.tabCapture` нельзя вызвать из content script, а конвейер `video` / `canvas` / `MediaRecorder` требует оконного контекста с DOM. Попап закрывается при потере фокуса, а у Service Worker вообще нет DOM, поэтому ядро записи живёт в **offscreen-документе**:

1. **Content script** (не внедряет интерфейс, только сообщает данные) определяет положение плеера примерно каждые 120 мс и передаёт фактический прямоугольник картинки вместе с базой вьюпорта (CSS-размер, `devicePixelRatio`, смещение visual viewport).
2. **background** при необходимости создаёт offscreen-документ и вызывает `chrome.tabCapture.getMediaStreamId()` внутри цепочки пользовательского жеста, получая `streamId`.
3. **Offscreen**-документ потребляет полный поток вкладки через `getUserMedia({ chromeMediaSourceId: streamId })` (видео + звук страницы).
4. Внутри **offscreen**: скрытое `video` воспроизводит поток вкладки → скрытый `canvas` кадр за кадром обрезает через `drawImage` → видеодорожка `canvas.captureStream(30)` объединяется с исходным `audioTrack` → `MediaRecorder` записывает (`video/mp4` в первую очередь, с постепенным откатом на `video/webm`) → фрагменты собираются в Blob.
   - Преобразование координат использует **измеренное соотношение** («размер захваченного кадра ÷ CSS-размер вьюпорта», модель contain с центрированными полями) вместо наивного `rect × devicePixelRatio`, что устраняет сдвиг на HiDPI-экранах и при масштабировании.
5. Offscreen-документ **не может** напрямую вызвать `chrome.downloads`: он отправляет `DOWNLOAD_FILE` в **background**, который выполняет загрузку и сообщает результат через `downloads.onChanged`.

Подробности — в `DESIGN.md`.

## Установка (разработка)

1. Откройте Chrome и перейдите на `chrome://extensions`.
2. Включите **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение** и выберите каталог `src/` этого репозитория (без сборки, ничего компилировать не нужно).

> Требования: Chrome ≥ 116 (`minimum_chrome_version`, нужен для `chrome.offscreen`); нативный вывод MP4 требует Chrome ≥ 126. Рекомендуется последняя стабильная версия.

## Использование

1. Откройте любую **страницу просмотра YouTube** (публичные видео; видео с DRM или только для участников запишутся чёрным экраном — это ограничение защиты браузера).
2. Нажмите значок расширения → нажмите **Начать запись** в попапе (держите вкладку видимой, а плеер — полностью в области видимости).
   - Если браузер/система не может выдать нативный MP4 (Chrome < 126 или нет кодировщиков H.264/AAC), попап сообщит, что сессия будет записана в WebM.
   - Во время записи на значке появляется красный бейдж `REC`. Закрытие попапа не останавливает запись — просто нажмите значок снова.
3. **Запись области** (опционально): нажмите **Запись области** → попап закроется → выделите прямоугольник на странице → нажмите **Записать выделение** (`Esc` выходит из режима выделения).
   - Во время записи кнопка **Стоп** автоматически размещается *вне* выделения, чтобы никогда не попасть в видео. Если выделение занимает почти весь вьюпорт и места нет, элементы на странице скрываются — останавливайте через попап или горячую клавишу.
4. В конце нажмите **Остановить и сохранить** → файл будет собран и загружен как `YouTube-ГГГГММДД-ЧЧММСС.mp4` (`.webm` при откате).
5. **Горячая клавиша**: на странице YouTube нажмите клавишу по умолчанию `R`, чтобы начать; нажмите снова, чтобы остановить и сохранить.
   - Нажмите **Настройки** в правом верхнем углу попапа, чтобы изменить её: кликните по полю клавиши и нажмите новую комбинацию, `Esc` отменяет. Изменения применяются мгновенно, перезагрузка страницы не нужна.
   - Горячая клавиша срабатывает только когда страница YouTube в фокусе, и никогда в полях ввода — поиске или комментариях. О конфликтах с горячими клавишами браузера или плеера сообщается в панели настроек.
6. **Тонкая настройка кадра** (сворачиваемый раздел внизу попапа): в редких конфигурациях (необычный зум, мониторы с разным DPI) может остаться небольшой фиксированный сдвиг — укажите значения в пикселях по вертикали / горизонтали (положительные = вниз / вправо).
7. **Во время записи страница блокируется маской** (режим «Весь плеер»):
   - Всё вне картинки закрыто полупрозрачным чёрным: кнопки и ссылки не нажимаются, колесо мыши и сенсорная прокрутка заблокированы, позиция прокрутки зафиксирована.
   - **Разрешено**: воспроизведение/пауза, перемотка, громкость, субтитры, скорость — всё, что является чистым управлением воспроизведением.
   - **Заблокировано**: клавиши прокрутки (Пробел, Page Up/Down, Home/End, стрелки Вверх/Вниз), полный экран `f`, театральный режим `t`, миниплеер `i`, выключение звука `m` и двойной клик по картинке — эти действия меняют раскладку или делают аудиодорожку беззвучной.
   - В маске вырезано отверстие под картинку, поэтому она не закрывает ничего записываемого и **никогда не попадает в итоговый файл**; под картинкой (над ней, если места мало) отображается надпись «Идёт запись · страница заблокирована».
   - Изменение размера окна браузера веб-страница запретить не может: при обнаружении изменения вьюпорта маска показывает предупреждение, а попап советует перезаписать (обрезка могла сместиться).
8. После остановки маска удаляется автоматически, страница возвращается в обычное состояние — без оставшихся узлов и слушателей.

### Форматы вывода

| Окружение | Вывод |
| --- | --- |
| Chrome ≥ 126 с кодировщиками H.264/AAC (например, свежий Chrome в Windows / macOS) | **MP4** (H.264 + AAC, `.mp4`) |
| Chrome < 126 | WebM (`.webm`) — попап объясняет причину |
| Chrome ≥ 126, но платформа без кодировщиков (некоторые сборки Linux) | WebM (`.webm`) — попап объясняет причину |

> Никакого перекодирования: когда MP4 доступен, он записывается нативно через `MediaRecorder` (без ожидания и потерь качества); иначе используется WebM.

### Разрешения

| Разрешение | Назначение |
| --- | --- |
| `tabCapture` | Ограниченное разрешение; захватывает картинку и звук текущей вкладки после клика пользователя |
| `downloads` | Сохраняет запись в локальную папку загрузок |
| `activeTab` | Временный доступ к текущей вкладке при нажатии на значок |
| `offscreen` | Создаёт offscreen-документ для захвата / обрезки / записи |
| `storage` | `session` хранит состояние записи и намерение запуска; `sync` — горячую клавишу и настройку кадра |

Никаких `host_permissions`, никаких сетевых запросов, никакого сбора пользовательских данных.

## Статическая самопроверка

```bash
python3 scripts/verify_extension.py
```

Покрывает: манифест / MV3 / обязательные файлы, ограничение доменом YouTube и порядок внедрения, минимальные разрешения, отсутствие сторонних зависимостей, синтаксис JS всех файлов (`node --check`), границы контекста API (content scripts не должны напрямую вызывать `tabCapture` / `downloads` / `offscreen`), границы внедрения на страницу (элементы управления должны быть в попапе; `content/guard.js` — единственный модуль, которому разрешено создавать DOM, и он должен вырезать отверстие под картинку, оставлять его пустым и удаляться после сессии) и границы модуля горячих клавиш.
